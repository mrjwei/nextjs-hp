## What I'm building now

**<ExtLink href="https://github.com/mrjwei/agent-loop">agent-loop</ExtLink> — coding agents under rules.** An open-source loop that turns GitHub issues into pull requests with headless Claude Code. A read-only triage agent keeps the issues in line with the plan, work agents build in parallel in their own worktrees, and an independent review checks every acceptance criterion. The loop, never an agent, merges low-risk changes, judged from the diff. Plans, high-risk changes and anything that alters the agents' own instructions wait for me. It grew out of my DEN build. I'm now hardening the review step as the autonomy goes up, and closing the outer loop: from an empty directory to a plan, issues, pull requests and merges, then back to planning.

**AI-drafted compliance records at DEN — pilot, moving onto AWS.** A system that turns daily work reports into audit-ready records, to replace spreadsheet workflows across the operator's welfare sites. An LLM drafts the records under a three-tier model — deterministic checks in code, LLM self-assessment, and mandatory human sign-off — so nothing is issued that a person hasn't confirmed. The pilot runs at one facility and is moving onto AWS ahead of a wider rollout.

**<ExtLink href="https://github.com/mrjwei/yuho-rag">yuho-rag</ExtLink> — retrieval over Japanese financial filings.** A RAG service over securities reports (有価証券報告書) pulled from the EDINET API, built in the open. It's early: the spec and the first filings are in, and retrieval and an evaluation suite in CI come next.

**Design in Git — design that lives where the code lives.** I'm moving design-system work into a repository, so tokens, components and the decisions behind them sit under version control and review, whether a person or a model made the change. The series starts with [I Was Reinventing Git in Figma](/posts/design-in-git/i-was-reinventing-git-in-figma).

**Writing, weekly.** Case studies from four years as a sole designer, starting with [From design assets to design intent](/projects/fueldelivery/from-design-assets-to-design-intent-building-a-shared-design-language-as-a-team-of-one), and an AI auditing series.

## Recently finished

**[Interlixir](/projects/interlixir) — research recordings to structured documents.** A cloud service that turns interview and usability-test recordings into structured Markdown research documents. An event-driven AWS pipeline chunks and transcribes the audio with self-hosted Whisper on Fargate, scaling on queue backlog, then redacts personal information and synthesises the document on Amazon Bedrock. A tool-using chat agent answers questions over your own data. Built for a QUT cloud-computing unit; the <ExtLink href="https://github.com/mrjwei/interlixir-public">code is public</ExtLink>.

**[Evaluating LLM security triage](/projects/ai-sec) — QUT capstone.** An evaluation harness over 146 labelled attacks across 14 techniques on a Wazuh SIEM. The most useful findings weren't about the model: logging design explained most detection gaps, and a lenient scoring rule had been inflating accuracy by more than 20 points.

**[LingoBun](/projects/lingobun) — my own AI product.** A vocabulary app built and hardened like production software: rate limits and cost caps on AI and text-to-speech calls, validated configuration, and 180 automated tests, shaped by rounds of user testing.

**[Strobe Assistant](/projects/strobe) — agents on AWS.** A conversational agent, an async pipeline that makes photos searchable and a daily autonomous agent, added to a photo-sharing app on Amazon Bedrock and ECS Fargate.
